# Woodlands Gutter Pros

Dependency-free gutter service website.

Run `python3 -m http.server 8000` here for local preview.

Generated from the portfolio gutter launch workspace. Public contact values are in `site-config.json`; launch_ready controls website indexing and requires the confirmed public phone plus completed page QA. The owner requested prompt crawl discoverability. Confirmed addresses and a gutter booking URL remain required to finish the GMB setup packs and online booking flow.
